隐私 · 本地设置

没有账号，没有统计脚本

本站不要求登录，不运行 Google Analytics、Plausible、Matomo、Umami 等统计脚本，也不做广告追踪。

本站会存什么

  • 主题设置：localStorage 的 `51invest-theme`，以及名为 `51invest-theme` 的 cookie，用来记住浅色、深色或跟随系统
  • 语言设置：localStorage 的 `51invest-language`，以及名为 `51invest-language` 的 cookie，用来记住中文或英文
  • 图表收藏：只存在浏览器的 localStorage，不上传服务器
  • 这些值只用于页面显示，不用于画像、广告或跨站追踪

托管方会看到什么

本站是静态站点，托管在 GitHub Pages。GitHub 可能按其平台规则记录访问日志（例如 IP、时间、请求路径和浏览器信息）；这些日志不由本站控制，也不进入本站的内容系统。

页面不包含第三方统计、广告或社交插件。外部链接会把你带到别的站点，那些站点有自己的隐私政策。

你可以怎么做

可以在浏览器设置里清除本站的 cookie 和 localStorage；清除后主题和语言会回到默认，图表收藏会丢失，正文阅读不受影响。

如果通过 GitHub issue 提交更正，issue 内容和你的 GitHub 账号信息是公开的；不要在 issue 里放不想公开的个人信息。

变更

如果以后加入统计、评论、账号或其他会处理个人数据的功能，会先更新本页，再上线。当前页面描述的是现在的实际行为，不是对未来功能的承诺。
